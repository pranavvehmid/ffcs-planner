# Code of Conduct

Be kind, be patient, and assume good intent. Everyone here is a student trying to make FFCS less painful.

- No harassment, insults or personal attacks.
- No sharing anyone's personal data (VTOP logins, registration numbers, marks).
- Critique code and ideas, not people.

Maintainers may remove comments, commits or contributors that break these rules. This follows the spirit of the [Contributor Covenant](https://www.contributor-covenant.org/).
